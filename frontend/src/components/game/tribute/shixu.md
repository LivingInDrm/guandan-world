## 统一流程的关键点

| 阶段 | 所有场景共性 | 场景差异 |
|------|-------------|---------|
| **0** | 都显示开始提示 | 规则描述不同（双下/单下/末游） |
| **1** | 都显示检测结果 | 抗贡成功 → 跳阶段5<br>未抗贡 → 进阶段2 |
| **2** | 都显示贡牌动画 | 1张或2张飞向贡池 |
| **3** | 都处理选贡 | 单下：自动分配动画<br>双下：用户选择界面 |
| **4** | 统一布局（进度+操作区） | 1人或2人还贡 |
| **5** | 都显示完成倒计时 | 抗贡显示豁免<br>正常显示上贡结果 |
